# 板块势能 · 五阶段模型

> 一套只观察「资金行为」的板块阶段判断框架：从无人问津，到资金进场，再到疯狂与退潮。
> 它的目标不是预测未来，而是每天回答两个问题——**这个板块现在处于哪个阶段？正在向哪个阶段移动？**

## 一张表看懂五个阶段

| 阶段 | 核心状态 | 典型特征 | 操作意义 |
| --- | --- | --- | --- |
| ① 沉寂 | 没有明显资金关注 | 量低、波动小、涨跌分散 | 不关注 |
| ② 发现 | 势开始形成 | 量开始放大、相对走强、上涨扩散 | 重点研究 |
| ③ 成型 | 资金持续推动 | 价量配合、上涨扩散、连续性增强 | 主要参与区 |
| ④ 加速/狂热 | 资金高度拥挤 | 巨量、快速上涨、涨停集中、波动极大 | 谨慎追高 |
| ⑤ 衰退/分歧 | 资金推动能力下降 | 巨量但涨不动、冲高回落、下跌扩散 | 减仓/退出 |

## 阶段全景：势的完整旅程

```
① 沉寂 ──► ② 发现 ──► ③ 成型 ──► ④ 加速/狂热 ──► ⑤ 衰退/分歧

          └── 并非单行道，随时可能折返 ──┘
```

一条势的完整旅程大致是 **沉寂 → 发现 → 成型 → 加速**；而狂热之后可能继续加速，也可能转入分歧直至衰退。但每一段都可能失败、回到沉寂（例如 **沉寂 → 发现 → 失败 → 回到沉寂**）。

判断每个阶段该看什么，本质是同一件事——**资金在做什么**：

> 发现区看「资金开始行动」；成型区看「资金持续行动」；狂热区看「资金是否过度拥挤」；衰退区看「资金还能不能推动价格」。

---

## ① 沉寂区 —— 没有资金行为，等待脚印

**这是什么：** 市场还没有明显行动。

**典型表现：**

- 成交额处于近期低位
- 涨跌幅较小
- 板块价格横盘或缓慢下跌
- 上涨 / 下跌家数没有明显倾斜
- 涨停、跌停都很少
- 每天的价格波动比较平淡

**关键认知：** 它最大的特点不是「跌」，而是——

> **没有明显的资金行为。**

**所以这里最重要的不是预测「它什么时候涨？」，而是：**

> **等待脚印出现。**

**操作意义：** 不关注。

---

## ② 发现区 —— 势开始留下脚印

> 这是我的系统最有价值的阶段。

**核心：** 钱开始进场，但趋势还没有完全确认。

**典型表现：**

- 成交额开始高于近期正常水平
- 价格开始摆脱原来的弱势
- 板块相对其他板块开始走强
- 上涨家数开始增加，下跌家数减少
- 少量股票开始明显强于板块
- 偶尔出现涨停
- 回调开始出现承接

**最关键的不是** 今天涨了 5%，**而是：**

> 原来没有人买 → 开始有人买 → 买盘开始影响价格。

**例如：**

| 成交额 | 涨幅 | 上涨家数 | 涨停数 |
| :---: | :---: | :---: | :---: |
| ↑ | ↑ | ↑ | ↑ |

而且这种变化**开始持续**——这就是：**势开始留下脚印。**

**这个阶段的意义：**

- 最值得研究。
- 但不代表马上买，因为 **发现 ≠ 成功**。

可能的两种走向：

| 走向 | 路径 |
| --- | --- |
| 失败 | 沉寂 → 发现 → **失败** → 回到沉寂 |
| 成功 | 沉寂 → 发现 → 成型 → 加速 |

**所以发现区本质上是：** 低确定性、高潜在赔率。

**操作意义：** 重点研究。

---

## ③ 成型区 —— 资金行为已被价格确认

**这是什么：** 资金行为已经被价格确认——也就是你之前说的「确认区」。

**典型表现：**

- 价格突破近期平台
- 成交额持续高于正常水平
- 上涨家数明显占优
- 涨停数量增加
- 跌停数量较少
- 板块连续走强
- 回调之后能够重新上涨
- 成交额增加能够产生实际的价格推进

**这里有一个特别重要的指标：**

> **成交额和价格必须配合。**

**例如 —— 好的成型：**

| 成交额 | 价格 | 上涨家数 | 涨停数 |
| :---: | :---: | :---: | :---: |
| ↑ | ↑ | ↑ | ↑ |

说明：**钱进来 → 价格上涨 → 越来越多股票参与。**

这是非常健康的势。

**操作意义：** 主要参与区。

---

## ④ 加速 / 狂热区 —— 势能加速

**这个阶段不是**「上涨 = 危险」，**而是：**

> 资金行为已经高度集中、极端化。

**典型表现：**

- 成交额极端放大
- 板块短时间快速上涨
- 大量股票涨停
- 上涨家数接近极端
- 龙头连续大涨
- 板块波动明显扩大
- 市场参与度达到极高水平

**例如：** 正常成交额 300 亿，突然：

```
成交额： 300亿 → 600亿 → 900亿 → 1500亿 → 2500亿
涨幅：     +3%  →  +5%  →  +7%
```

这就是明显的：**势能加速。**

**但这里必须记住：**

> **狂热 ≠ 马上见顶**

狂热之后可能：

| 走向 | 路径 |
| --- | --- |
| 继续向上 | 狂热 → 继续加速 → 更高 |
| 转向退潮 | 狂热 → 分歧 → 衰退 |

**所以我的系统不应该说「狂热，卖。」而应该说：**

> **「趋势非常强，但风险收益比正在恶化。」**

**操作意义：** 谨慎追高。

---

## ⑤ 衰退 / 分歧区 —— 资金推动效率下降

**这是整个模型非常重要的一个阶段。**

因为：**势真正消失的时候，往往不是价格已经跌很多，而是资金开始失去推动价格的能力。**

**三种值得警惕的典型迹象：**

**第一种 —— 量增价滞（钱越来越多，价格越来越推不动）**

| 时间 | 成交额 | 涨幅 |
| :---: | :---: | :---: |
| 先 | ↑↑↑ | +5% |
| 后 | ↑↑↑↑ | +0.5% |

> 这非常值得警惕：钱越来越多，但是价格越来越推不动。

**第二种 —— 冲高回落（盘中冲进去，收盘抛压出来）**

| 指标 | 数值 |
| :---: | :---: |
| 最高 | +6% |
| 收盘 | +1% |

> 盘中有资金冲进去，但收盘出现大量抛压。

**第三种 —— 上涨家数回落 + 跌停增加（板块内部开始分化）**

```
上涨家数： 80% → 55% → 35%
同时：     跌停开始增加
```

> 这意味着：板块内部开始分化。

**关键认知：** 所以衰退区不是简单的「跌了」，而是——

> **资金推动效率下降。**

**操作意义：** 减仓 / 退出。

## 贯穿五阶段的一条主线

无论处于哪个阶段，观察的落点始终是资金：

> 发现区看「资金开始行动」；
> 成型区看「资金持续行动」；
> 狂热区看「资金是否过度拥挤」；
> 衰退区看「资金还能不能推动价格」。
