# 板块势能 · 五阶段模型

> 一套只观察**资金行为**的板块阶段判断框架。
>
> **主线（从头到尾只有这一条）**：
> 脚印出现 → 脚印变多 → 脚印方向一致 → 脚印密集 → 猎人太多 → 推进成本上升 → 猎物消失。

**它不是技术指标模型，而是资金行为模型。** 这句话决定了后面所有取舍。

**核心哲学**：只观察**资金行为在价格和成交量上的结果**。

---

## 一、模型只回答两个问题

| # | 问题 | 输出 | 在哪一层回答 |
| :-: | --- | --- | :-: |
| 1 | 这个板块**现在**在哪个阶段？ | ① ② ③ ④ ⑤ | **判断·Layer 1 · Regime** |
| 2 | 它**正在往哪里**移动？ | ↑ 升温 / → 维持 / ↓ 降温 | **判断·Layer 2 · Momentum** |

> **位置告诉你该不该看，方向告诉你该不该动手。**
> 真正值得交易的往往不是「成型」，而是「**成型 + 正向移动**」。

---

## 二、指标纪律（最重要的一条规则）

每个指标**必须回答下面五个问题之一**，答不上来就删掉：

```
钱来了没有？  →  钱有没有留下？  →  有没有更多股票参与？ →  钱产生了多少价格推进？  →  是不是已经太拥挤？
```

---

## 三、板块层：两个因子（4 个指标）

### 3.1 Participation · 资金参与度 —— 钱来了多少

> Participation 用两个维度回答「钱来了没有」：
> **AbsPart 看绝对量**（钱有没有进来），**RelPart 看相对量**（钱是不是冲它来）。两者必须一起看。

**基准（分层，父级减去自身）**：

```
全A股市场
 └─ 一级板块  →  基准 = 全A股市场 − 该一级板块
     └─ 二级板块  →  基准 = 其一级母板块 − 该二级板块
         └─ 个股  →  基准 = 其二级板块 − 该个股
```

| 指标 | 公式 | 回答什么 |
| --- | --- | --- |
| **AbsPart**（绝对） | `V ÷ MA20(V)` | 钱有没有进来（相对自己过去 20 天） |
| **RelPart**（相对） | `AbsPart ÷ AbsPart(基准)` = `[V ÷ B] ÷ [MA20(V) ÷ MA20(B)]` | 钱是不是冲它来（相对同级其余部分） |

> `V` = 成交额，`B` = 父级成交额 − 自身成交额。
> RelPart 的等价读法：**今日在同级中的成交份额 ÷ 自己 20 日平均份额**——份额升了，就是钱在倾斜过来。

**判读（2×2）**：

| | RelPart > 1 | RelPart < 1 |
| --- | --- | --- |
| **AbsPart > 1** | 增量 + 超额 → **钱主动冲它来，主线启动** | 放量但跑输同级 → **被动跟随，不是主动吸金** |
| **AbsPart < 1** | 缩量但相对吸金 → **矮子里拔将军（相对抗量）** | 缩量且跑输 → **资金在撤离 / 被抛弃** |

> **连续性比爆发更重要**：`0.8→0.9→1.0→1.1→1.3` 比 `0.7→2.0` 更有意义。
> 连续性直接从 AbsPart / RelPart 自己的**时间序列**读，不单独立「趋势」指标。

### 3.2 Cost · 推进成本 —— 推高/砸低价格要吃掉多少换手

> 单日、不分方向：衡量「价格每移动 1% 要消耗多少换手」，不管涨还是跌。
> 方向由 §3.1 的「涨幅」单独看——成本只回答「费不费劲」。

```
AbsCost = 当日换手率 ÷ |当日涨跌幅|
RelCost = AbsCost ÷ Median(过去 20 日 AbsCost，不含当天)
```

| 指标 | 公式 | 回答什么 |
| --- | --- | --- |
| **AbsCost** | 当日换手率 ÷ \|当日涨跌幅\| | 今天每移动 1% 花了多少换手（不论涨跌） |
| **RelCost** | AbsCost ÷ 过去 20 日中位数 | 相对自己的常态，是更容易还是更困难（>1 = 更费劲） |

> **为什么用 \|涨跌幅\|、不分方向**：成本只答「费不费劲」，方向交给「涨幅」。
> 于是：
> - 涨幅 > 0 且 RelCost 低 → 轻松上涨（筹码稳，强）
> - 涨幅 > 0 且 RelCost 高 → 费劲上涨（抛压重，弱）
> - 涨幅 < 0 且 RelCost 高 → 费劲下跌（下面有人接，支撑强）
> - 涨幅 < 0 且 RelCost 低 → 轻松下跌（无人承接，弱）
