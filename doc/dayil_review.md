# 交易日志模板 · 板块势能五阶段模型

> 配套 `model.md`。记录的目的不是留档，是**可校准**——
> 必须记下**当时的理由和预测**，而不只是结果。结果谁都记得，理由三天后就全是马后炮。

**使用原则（三条，比模板本身更重要）**

1. **每天 10 分钟封顶。** 模板越重越写不下去，写不下去就什么都留不下。宁可字段少而连续，不要完整而中断。
2. **月度校准的 C、D 两项是核心。** C 校准**判断力**（阶段分得对不对），D 校准**执行规则**（checklist 是不是把好票筛掉了）。其他都是辅助。
3. **月度只改一件事。** 同时改三条规则，下个月无法归因——这是自我优化最常见的死法。

## 一、每日晚间复盘（5–10 分钟）

```markdown
## 2026-09-24 周四

### 0. 环境（一句话，不要展开）
大盘：___   板块分化程度：高 / 中 / 低
今日主线：___（如果说不出，就写"无主线"——这本身是重要信息）

### 1. 板块扫描
轨A 自上而下：一级升温 → ___、___
  └ 对应最强二级：___（阶段 ②，RelPart 1.3 连续3日，RelCost 0.8）
轨B 自下而上：二级异动 → ___
  └ 其一级是否**跟随升温**？ 是 / 否   → 否则半仓 + 缩短持有周期

  ⚠️ 判据是"一级是否在跟随"，不是"一级是否已强势"（后者是滞后确认）

### 2. 池子变动
新增：___（理由见候选卡）
出池：___（原因：板块进④⑤ / RS连续2日<0 / RelPart连续2日<1 / 满5日未成型 / 主动淘汰）
当前：观察池 __个（上限12）  待买池 __只（上限5）  持仓 __只（上限3）

### 3. 持仓判断
| 标的 | 持有天 | 板块阶段 | RS | RS偏离 | RelPart | RelCost | 符合预期? | 动作 |
|---|---|---|---|---|---|---|---|---|
| ___ | 3 | ③ | +2.1 | +0.4 | 1.4 | 0.7 | ✅ | 持有 |

不符合预期的，写明**具体哪一条**坏了：___

  ⚠️ RS偏离 ≈ 0 或略 < 0 但 RS 仍显著 > 0 = **高位维持，不是卖点**
     （持续领涨会把自己的20日中位数抬高，RS偏离自然衰减）
     真卖点：RS 本身转负，或 RS 收敛 + RelCost 抬头

### 4. 明日计划（写死，盘中不改）
买入：___ ，执行条件三选三**必须全过**：
  □ 开盘高开 < 3%    □ 不破昨收    □ 量能不缩
卖出：___ ，开盘卖 / 尾盘卖
买入时点：14:45–14:55（避开 14:57 后的收盘集合竞价）

### 5. 自评（一句话）
今天有没有想改规则？有的话是为什么：___
```

> **第 5 条是整个模板里最有价值的一行。**
> 想改规则的冲动几乎总是出现在浮亏或踏空时。记下来，一个月后回看会非常刺眼。

## 二、候选入池卡（每个候选写一次，写完不改）

```markdown
### [板块名 / 个股名]   入池 2026-09-24

板块：___（一级：___ ，跟随中？是 / 否）
入池时阶段：②

因子快照（**记数值，不记感觉**）
  板块层  AbsPart ___   RelPart ___   涨跌家数 __/__   RelCost ___
  个股层  RelPart ___（>1 连续 __ 日）
          RS ___        RS偏离 三日 ___ / ___ / ___（需 >0 且递增）
          RelCost ___（配合当日涨跌方向读，不单独排序）
  位置    近20日涨幅 ___%    距60日高点 ___%
  风控    流通市值 ___亿     20日均额 ___亿     20日波动率 ___

主线 or 补涨？  RelPart > 1 已连续 __ 日
  └ 持续 > 1 = 主线票；刚转 > 1 且此前长期 < 1 = 补涨票（③后段的陷阱）

买入逻辑（一句话）：___
**预期路径**：未来 __ 日内应该出现 ___
**证伪条件**：如果出现 ___，说明我看错了
**失效日期**：2026-10-08（5 个交易日，到期自动出池）
```

> 因子必须记**数值**。三周后你看到 "RelPart 1.15" 和看到 "资金在流入"，
> 是两种完全不同的复盘质量。

## 三、交易记录（买、卖各一次，卖出后第5日补记追踪）

```markdown
### [标的]   买入 2026-09-25

买入：14:50   价 ___   仓位 ___%
买入时板块阶段：___     个股在板块内 RS 排名：第 __ 名
三条执行 checklist：□ 高开<3%   □ 不破昨收   □ 量能不缩
选它不选 RS 第一名的理由：___
  （正确理由是"尾盘买不进 / 要付溢价"这类**执行约束**，
    不是"RS第一所以不买"——②阶段的主线发起者常常就是RS第一且买得到）

---

### 卖出 2026-09-30    持有 4 日    盈亏 ___%

退出原因（**单选**，不要写"综合判断"）：
  □ 不符合预期（具体哪条：___）
  □ 板块进入 ④ / ⑤
  □ RS 转负
  □ 硬边界 −8% 或跌破买入日最低价
  □ 其他：___

卖出时因子读数：RS ___   RS偏离 ___   RelCost ___   板块阶段 ___

【卖出后 5 日追踪】（第 5 日补记）
后续涨跌：___%   →   卖早了 / 卖对了 / 卖晚了
```

> **「卖出后 5 日追踪」是这张表里唯一能让你进步的字段。**
> 它直接回答"我的退出规则是太松还是太紧"——
> 这是散户最普遍、也最难自我发现的问题。

## 四、月度校准（每月一次，30 分钟）

前三张表记的是过程，这张表把它变成**可行动的结论**。

```markdown
## 2026年9月 月度校准

### A. 基础统计
交易 __ 笔     胜率 __%     平均盈 __% / 平均亏 __%     盈亏比 __
平均持有 __ 日     最大单笔回撤 __%     当月总收益 __%

### B. 按退出原因分类
| 退出原因 | 笔数 | 平均收益 | 卖后5日平均 | 结论 |
|---|---|---|---|---|
| 不符合预期 | 5 | +2% | +4% | ⚠️ 系统性卖早 |
| 板块进④   | 3 | +8% | −3% | ✅ 时点准确 |
| RS转负     | 2 | −1% | −2% | ✅ |
| 硬止损     | 1 | −8% | −12% | ✅ 救了 |

→ **若某类"卖后5日"持续为正，说明该退出规则过紧，需放宽。**

### C. 阶段判断准确率 ⭐核心
我判为 ② 的板块，3 日后真的进入 ③ 的： __ / __ = __%
我判为 ④ 的板块，后续确实走弱的：      __ / __ = __%
我判为 ③ 的板块，还能再走 3 日以上的：  __ / __ = __%

→ 低于 50% 说明**阶段划分标准**有问题，不是运气问题。
   此时该改的是阈值定义，不是交易规则。

### D. 看中但没买的候选 ⭐核心
候选 __ 个，实际买入 __ 个，未买 __ 个
未买的当中，次日 + 第3日跑赢大盘的： __ 个 = __%
已买的当中，次日 + 第3日跑赢大盘的： __ 个 = __%

→ **若"没买的"表现持续优于"买了的"，说明观察日 checklist 过严**，
   你在系统性筛掉最强的那批（它们往往高开 > 3%）。
   考虑把高开阈值从 3% 放宽到 5%，或改为"高开但不破开盘价即可买"。

### E. 纪律
违规次数：__（未按前晚计划执行 / 盘中临时改规则 / 超仓位 / 无信号交易）
每次的原因：___
→ 亏损来源里，**执行偏差**通常大于**判断错误**。这一栏比 A 栏更值得看。

### F. 下月只改一件事
___

**一次只改一个变量，否则下个月无法归因。**
```

## 附：常用因子速查

| 层 | 因子 | 公式 | 读法 |
|---|---|---|---|
| 板块 | AbsPart | `V ÷ MA20(V)` | >1 钱进来了 |
| 板块 | RelPart | `AbsPart ÷ AbsPart(基准)` | >1 钱冲它来 |
| 板块 | 涨跌家数 | 板块内上涨家数 / 总家数 | 广度；被单票绑架则**不做** |
| 板块 | AbsCost | `换手率 ÷ \|涨跌幅\|` | 推进费不费劲 |
| 板块 | RelCost | `AbsCost ÷ Median(20日 AbsCost)` | >1 比平时费劲 → ④ 预警 |
| 个股 | AbsPart | `V ÷ MA20(V)` | 钱进这只票没 |
| 个股 | RelPart | `AbsPart ÷ AbsPart(板块−个股)` | >1 专门冲它来；**看连续天数**辨主线/补涨 |
| 个股 | RS | `个股涨跌幅 − 板块涨跌幅` | 跑赢多少个点（**强度/位置**） |
| 个股 | RS偏离 | `RS − Median(20日 RS)` | 跑赢在加强还是衰减（**方向/加速度**） |
| 个股 | AbsCost | `换手率 ÷ \|涨跌幅\|` | 自己筹码松紧 |
| 个股 | RelCost | `AbsCost ÷ Median(同板块其余个股 AbsCost)` | 比同伴费不费劲 |

**核心哲学（板块层与个股层通用）**

> **位置告诉你该不该看，方向告诉你该不该动手。**
> 板块层：阶段 = 位置，升温/降温 = 方向
> 个股层：RS = 位置，RS偏离 = 方向

**按阶段切换选股逻辑**

| 板块阶段 | 选什么 | 一句话 |
|---|---|---|
| ② 启动 | RS偏离 > 0 且三日递增，RelPart 刚转 > 1 | 买**正在变强的** |
| ③ 主升 | RS 高 且 RelCost 低，RelPart 持续 > 1 | 买**已经最强的** |
| ④ 分歧 | 不开新仓 | **谁都不买** |

**硬性过滤（不可协商）**

```
流通市值 > 50亿        20日均成交额 > 2亿
仓位上限 3 只，分属不同一级板块
硬边界：−8% 或跌破买入日最低价，无条件
```
